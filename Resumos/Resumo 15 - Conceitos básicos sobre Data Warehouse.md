**O que é um Data Warehouse?**

Um data warehouse é um sistema de armazenamento centralizado que reúne dados de várias fontes, organizando-os de forma otimizada para consultas e análises. 

Ele é projetado para auxiliar em tomadas de decisão, permitindo consultas rápidas em grandes volumes de dados. Diferente dos bancos de dados transacionais, o data warehouse é estruturado para análises complexas, como geração de relatórios e mineração de dados usando o método OLAP (Online Analytical Processing). 

Geralmente ele armazena dados de longo prazo e é a base para processos de negócio.

Os objetivos de um data warehouse são:
- Prover segurança aos dados
- Servir como uma fundação para melhorar a tomada de decisões das organizações
- Ser aceito e aprovado pela comunidade para ser considerado bem sucedido

O gerente de data warehouse é quem coordena  a estrutura de dados, as responsabilidades do gerente são:
- Entender  os usuários e suas áreas de atuação
- Determinar as decisões de negócios que os usuários querem realizar por meio do DW
- Identificar os melhores usuários.
- Identificar potenciais novos usuários.
- Selecionar os dados mais efetivos a serem integrados e apresentados no DW.
- Tomar as interfaces de usuário e aplicações simples aos seus usuários.
- Garantir que os dados são confiáveis.
- Buscar e monitorar as fontes de dados e adaptar para o DW.
- Publicar os dados com regularidade.
- Manter a confiança dos usuários de negócios.
- Manter os usuários, executivos e chefes satisfeitos.

- Fonte de Sistemas Operacionais: Correspondem ao banco de dados, ou disposição de dados e informações
- Área de testes de dados: Serve para limpar, combinar e padronizar os dados adquiridos nas fontes, de acordo com dimensões específicas. Também é responsável pelo armazenamento e o processamento 
desses dados.
- Área de apresentação de dados: É onde será realizada a entrega dos dados armazenados na área de testes.
- Ferramentas de acesso aos dados: São utilizadas para gerar relatórios, realizar análises, realizar mineração de dados de pontuação e revisão dos dados, além de acessar.
