# Mineração de Dados em DW
>[!Note]
>Resumo 19 | Especialização em Arquitetura de Software por Bruno Rijo

Mineração de dados ou Data Minings, faz parte de um processo chamado **Descoberta do Conhecimento em Banco de Dados (Knowledge Discovery in Databases - KDD)**.

O objetivo é descobrir padrões úteis em dados para fornecer subsídios às tomadas de decisão, é o que chamamos de Inteligência de negócio.

A KDD é composta por 5 fases:

1ª etapa - seleção dos dados
Identificar de que fontes os dados serão extraídos, podem ser provenientes de planilhas, aplicações, API’s de terceiros além de bancos de dados tradicionais. Após identificadas, será necessário selecionar as que serão utilizadas, e fazer um pré-processamento dos dados.

2ª etapa. Pré-processamento dos dados
Consiste em eliminar inconsistências, redundâncias, problemas relacionais e etc .. é a maior etapa do processo de mineração, tomando cerca de 80% do tempo.

3ª etapa. Transformação dos dados
Com os dados pré-processados, os dados são transformados em um schema para ser utilizado.

4ª Etapa. Mineração
Utiliza ferramentas que permitem a seleção de padrões, realizando a descoberta de conhecimento.

5ª Etapa. Interpretação
Uma vez que os dados foram adquiridos, são utilizadas ferramentas que utilizarão as informações para gerar os relatórios qu serão usados nas tomadas de decisão.

A mineração utiliza técnicas de IA para encontrar relações de similaridade ou discordância entre os dados, o objetivo é encontrar automaticamente padrões, anomalias e regras como propósito de transformar os dados em informações para a tomada de decisões ou avaliações de resultados.

Bases de dados transacionais, processadas com OTP (Online Transaction Processing) e OLAP (Online Analytical Processing) não estão prontas para a mineração.

Pra refrescar nossa memória OTP consiste na execução de várias transações simultâneas, como compras, envio de mensagens e etc … enquanto o OLAP facilita consultas de B.I. uma vez que são otimizadas, concentrando todos os dados em um único local para fornecer informações com maior performance, com foco no processo analítico, para tomada de decisões.

Exemplos de relação descoberta através de mineração de dados.
Relação de homens casados e a compra de fraldas e cervejas no Walmart.
Anomalias de vendas em lojas brasileiras, identificando a demanda de produtos específicos por região.

Dentre as técnicas de mineração de dados, pode-se destacar:
Associação
Descrição de classes
Classificação
Agrupamento(clustering)
Descoberta de padrões sequenciais
Descoberta de padrões em séries temporais
Regressão
Redes neurais
Algoritmos genéricos
