Federação de Nuvens
>[!Note]
>Resumo 22 | Especialização em Arquitetura de Software por Bruno Rijo

Uma federação de nuvem é a interconexão entre duas ou mais nuvens com intento de compartilhar dados e serviços entre dois provedores de nuvem diferentes.

As principais características são:
- Os provedores são agregados
- Compartilhamento de Serviços
- Interoperabilidade: Que é o acesso transparente a diversos provedores de serviços sem necessidade de compreender a fundo os protocolos de acesso ou interfaces de comunicação.
- Migração: Permitindo que um usuário seja capaz de migrar dados diretamente de um provedor para outro. Exemplo: Quando um contrato expira ou quando surge um novo produto de concorrente, se as nuvens fizerem parte da mesma federação, o cliente pode migrar seus dados diretamente, caso não sejam parte da mesma federação, o cliente necessitaria copiar os dados para sua máquina e então fazer upload no novo serviço.
- Redundância: Se refere a replicação dos dados em mais de um provedor, garantindo que não haverá indisponibilidade de serviços, nem perda de dados em caso de interrupção de um dos serviços.
- Compartilhamento: Pode ocorrer quando um usuário particiona os seus dados em diversos provedores de serviços diferentes com intenção de garantir a confiabilidade de seus dados, e com a federação de nuvem o acesso a esses bancos de dados é unificado.

A federação pode ser vertical ou horizontal, e esse modelo varia de acordo com o modelo de serviço disponibilizado pelo provedor de nuvem (Iaas, Paas, Saas).

No modelo vertical o compartilhamento desses serviços ocorre entre os modelos de serviços, enquanto no horizontal o compartilhamento ocorre sempre em provedores com o mesmo modelo de serviços. 

Os principais provedores de serviço de nuvem da atualidade são: AWS, Azure e o Google Cloud.
